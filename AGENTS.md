# Agent Instructions

This file provides guidance to agents when working with code in this repository.

## Project Overview

VitePress documentation site for **Luca**, a minimalistic decentralized tool, skill, and pipeline manager for macOS and Linux. Hosted on GitHub Pages at `luca.tools`.

## Development

```sh
npm install          # install dependencies (first time)
npm run docs:dev     # local dev server with hot reload at http://localhost:5173
npm run docs:build   # production build → docs/.vitepress/dist/
npm run docs:preview # preview the production build locally
```

## Architecture

VitePress 1.x project. Content lives in `docs/` as Markdown files.

- **`docs/.vitepress/config.ts`** — Full site config: nav, sidebar (5 collapsible groups), head tags (GA, OG, JSON-LD), theme, sitemap, search.
- **`docs/.vitepress/theme/index.ts`** — Extends VitePress default theme; imports `custom.css`.
- **`docs/.vitepress/theme/custom.css`** — Hides the dark-mode toggle (site is forced dark); adds `.home-install` and `.home-whats-new` styles for the home page sections below the hero.
- **`docs/public/`** — Static assets served verbatim: `CNAME` (luca.tools), `install.sh`, `uninstall.sh`, `images/`, `_redirects`, `robots.txt`.
- **`docs/index.md`** — Home page (`layout: home`): hero, 6-feature grid, install snippet, pipeline "What's New" callout.
- **`docs/manifesto.md`** — Manifesto page (`layout: page`, no sidebar).
- **`docs/getting-started/`** — Installation, Quick Start.
- **`docs/tools/`** — Tool Management section (4 pages).
- **`docs/skills/`** — Skill Management section (4 pages).
- **`docs/pipelines/`** — Pipeline Engine section (8 pages).
- **`docs/ecosystem/`** — Ecosystem section (3 pages: LucaScripts, GitHub Actions, LucaWorkflows).

## Deployment

GitHub Actions (`.github/workflows/deploy.yml`) builds on push to `main` and deploys `docs/.vitepress/dist/` to GitHub Pages. No manual deploy step.

## Key Design Decisions

- Theme: VitePress default dark (forced via `appearance: 'dark'` + CSS hiding the toggle). No custom accent color.
- Logo: `/images/luca-logo-alt.svg` (grayscale SVG).
- `cleanUrls: true` — no `.html` in URLs.
- The DocC API reference at `luca.tools/Luca/documentation/lucacli/` is a separate system (generated by CI in the Luca repo) and is linked externally from the top nav — do not modify it here.
